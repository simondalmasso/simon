# SIMONweb

Personal work index for Simón Dalmasso.

Production: https://simon.simondalmasso44.workers.dev

## Positioning

SOFTWARE · SYSTEMS · STORE · CRM · UX

## Stack

Zero-runtime-dependency static site: semantic HTML, CSS, ES modules and a short-lived Canvas 2D ident, deployed with Cloudflare Workers Static Assets.

## Experience

- 6.7 s cinematic first-load ident
- spectral energy field + kinetic service typography
- landing transition into a compact asymmetric project board
- eight verified live project destinations
- lazy live iframe previews where the target permits framing
- protected-preview fallback where framing is denied
- pointer-reactive motion, rubber-band drag and spring return on desktop
- email + WhatsApp quick contact
- responsive and reduced-motion paths

## Verification

```bash
npm run verify
npm run deploy:dry
```

## Architecture

- `src/data/projects.js` — project destinations and embed capability
- `src/main.js` — intro choreography, lazy previews and board physics
- `src/styles.css` — visual system, landing states and responsive rules
- `_headers` — Cloudflare Static Assets security headers
- `DESIGN.md` — design contract
- `MOTION.md` — motion/performance contract
- `wrangler.toml` — Cloudflare configuration
